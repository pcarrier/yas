# Local should be instant. Remote should survive.

- Today: the full feature set runs on Linux x86_64/arm64; macOS arm64 and Windows x86_64 provide PTY multiplexing.
- Open the workspace in a modern browser on a laptop, tablet, or phone.
- Keep IME, clipboard, pointer, touch, audio, and video feeling native.
- Pace every viewer independently, from a local socket to a high-latency WAN.
- Drop packets only where loss is safe; keep one ordered, reliable authority.
- Require no external database, display server, or GPU.
- Every v1 family is implemented; full cross-platform, load, latency, and fuzz qualification is still open.
