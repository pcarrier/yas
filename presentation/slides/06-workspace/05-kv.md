# Small state needed a home

- Store persistent byte-key/value namespaces by prefix and watch them in lexical order.
- Every entry carries hash, modification revision, timestamp, and optional inline value.
- Read inline or through Transfer; stage and hash large values.
- `PUT`, `DELETE`, or transactional `BATCH` with revision/hash preconditions and operation IDs.
- Deduplication survives a server restart.
- Keep shared app state, remotes, extension intent, and workspace sessions here—not files.
