# Git without parsing Git's prose

- Watch `HEAD`, refs, remotes, operations, status, upstreams, stashes, and worktrees as they change.
- Ask typed questions: resolve, merge-base, log, tree, blob, diff, patch, index, discover, blame, reflog, worktrees.
- Keep SHA-1/SHA-256 identity; page typed results; move large bodies through Transfer.
- Re-run watched queries when refs move—without opening a generic command tunnel.
- Preserve files, rows, spans, gaps, merge bases, and text/binary modes in structured patches.
- Retry fetch safely with phases, counters, and one final record per remote ref.
