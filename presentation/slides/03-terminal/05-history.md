# The terminal is already parsed. Use it.

- **Read what is there:** show the viewport as plain text or ANSI, optionally after resize.
- **Page through everything:** scrollback + viewport by top/bottom offset, line limit, or append cursor.
- **Search across terminals:** score visible text/title/scrollback; ripgrep-compatible grep; rejoin soft wraps.
- **Copy exactly:** cell ranges retain overflow text and hyperlink context.
- **Understand commands:** OSC 133 gives stable IDs, status, exit, timing, ranges, and command text.
- **Wait for outcomes:** bounded command output, server-side completion or regex wait, continuation cursors.
