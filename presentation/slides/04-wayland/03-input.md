# Input is where fake desktops fall apart

- **Keyboard:** physical key registry, press/release/repeat, modifiers, guaranteed release on focus loss.
- **Text:** committed UTF-8 plus preedit cursor/selection; non-ASCII travels through text input.
- **Pointer:** motion, five buttons, smooth axes, wheel detents, source/stop, relative/constrained motion.
- **Cursor:** named or custom RGBA, with hotspot, scale, or hidden state.
- **Touch:** direct multi-contact delivery; optional tap, drag, finger-scroll, long-press pointer compatibility.
- **Coordinates:** signed 32.32 fixed-point positions in the app's native-resolution frame; remote pointer/touch marks expire automatically.
