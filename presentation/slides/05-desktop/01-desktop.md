# A desktop app is more than its pixels

- Tray icons and notifications arrive as live, revisioned state—not pixels baked into a desktop stream.
- **StatusNotifier:** icon/attention/overlay, tooltip, activate, secondary activate, scroll.
- **DBusMenu:** normalized bounded tree, icons, revision-checked actions.
- **Notifications:** app/content icons, replacement, expiry, actions, replies, progress, close reasons.
- **In the browser:** status bar, menus, active cards, foreground toasts, opt-in system notifications.
- Apps share a private D-Bus; the host desktop bus is never exposed.
