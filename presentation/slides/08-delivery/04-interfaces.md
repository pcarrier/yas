# Humans and agents use the same resources

```bash
yas open
yas terminal start htop
yas terminal show 1
yas run --in /src/yas -- cargo test
yas surface capture 1
yas --on prod git status
```

- Open the interactive workspace in a browser.
- Script the same resources from the CLI.
- Embed live terminals and surfaces in React or Solid.
- Let computer agents operate the workspace through the published skill.
