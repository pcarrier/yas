# One command to start. One command to share.

Unix:

```sh
curl https://yas.run | sh
yas open
```

Windows PowerShell:

```powershell
irm https://yas.run/install.ps1 | iex
yas open
```

Share over WebRTC—read-write passphrase, with a derived read-only token when needed:

```sh
yas share
```

Nothing to configure. No required external dependencies.
